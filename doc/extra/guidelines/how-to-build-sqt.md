# How to Build SQT

Currently, Windows is the only supported platform for building SQT. To build SQT, install the latest version of Visual Studio 2022, open the `sqt.sln` solution file, and build the solution. 

The output of the build will be located in the `build\out\<Platform>\<Configuration>` directory, where `<Platform>` is the target platform (e.g., `x64`) and `<Configuration>` is the build configuration (e.g., `Debug` or `Release`).
